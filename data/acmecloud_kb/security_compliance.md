# Security and Compliance

## Encryption

All data is encrypted at rest with AES-256 and in transit with TLS 1.3.
Backups are encrypted with per-tenant keys, which are rotated every 90 days.

## Certifications

AcmeCloud has been SOC 2 Type II certified since 2023 and ISO 27001 certified
since 2024. A GDPR Data Processing Agreement (DPA) is available on request for
all plans.

## Audit and testing

Audit logs are retained for 365 days on all plans. On the Enterprise plan,
audit logs can additionally be exported to a customer-owned S3 bucket. An
independent third party performs a penetration test annually.

Security vulnerabilities should be reported to security@acmecloud.example.

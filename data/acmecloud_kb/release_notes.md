# Release Notes and Deprecations

## Release history

Release v3.0, codenamed "Kestrel", shipped in June 2025 and introduced Flows
(orchestration DAGs).

Release v3.1, codenamed "Lyra", shipped in October 2025. It made multi-factor
authentication mandatory for admin accounts and introduced SCIM provisioning
for Enterprise.

Release v3.2, codenamed "Meridian", shipped in January 2026. It made Lenses
(analytics dashboards) generally available.

## Upcoming: v4.0

Release v4.0 is scheduled for March 2026. It will remove the deprecated
`acme-py` Python package and the legacy REST v2 API.

## Deprecation policy

Breaking API changes are announced at least 12 months before removal.

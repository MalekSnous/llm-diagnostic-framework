The key insight: optimization can hurt

Real results from the medical entity-extraction case study — bigger isn't better, and generic "best practices" can degrade a strong model.

  • ✅ Smaller models benefit most from optimization (Phi-2: +28%).
  • ❌ Strong models can degrade with generic strategies (GPT-4o-mini: −8.8%).
  • 💰 GPT-4o cost 10× more yet performed worse than GPT-4o-mini.
  • 📊 Baseline testing is mandatory — theory doesn't predict real performance.

Try it in 30 seconds

The test suite is fully offline (mocked LLM client) — no API key needed to run it.

git clone https://github.com/MalekSnous/llm-diagnostic-framework.git
cd llm-diagnostic-framework
pip install -e ".[dev]"
make test                      # offline, no cost

# Run the RAG document-QA study (needs an API key)
pip install -e ".[rag]"
make run-rag-study model=gpt-4o-mini

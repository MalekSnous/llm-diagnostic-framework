Findings

  • Best quality: gpt-4o reaches F1 71.3%.
  • Prompt engineering helps most on claude-sonnet-4-6 (+52.9 F1 points).
  • Low baseline ≠ weak model: claude-sonnet-4-6 scored low at baseline mainly by answering in prose; few-shot standardised the output format (hence the large jump). Read baseline-vs-prompt as much about output format as raw capability.
  • Cost spread is huge: claude-sonnet-4-6 costs ~135× more than groq/llama-3.1-8b-instant for this run.
  • Best value (F1 per $): groq/llama-3.1-8b-instant.
